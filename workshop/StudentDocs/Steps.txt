Day 1:
*********************************
0. Check the Python version & ollama Installation:
    Windows: python --version | py --version | python -V
    Mac: python3 --version | python3 -V
    Windows/Mac: ollama list
Github Desktop:
1. Clone Repository using Github Desktop
2. Open the cloned repository in VS code

In VS Code: Open terminal -> open command prompt:
1. Create a folder in Explorer as "Workshop"
    Inside "Workshop" folder. Create Virtual Environment (Execute the following in cmd prompt)[One-time activity]: 
    1. python -m venv .venv
    2. Activate the virtual environment:
	    .venv\Scripts\Activate.bat      	//Win (to be done every day)
	    source .venv/bin/activate		    //mac (to be done every day)

3. Inside "Workshop" go on to Create a folder "Day1"

4. Installations(to be done inside virtual environment):
	pip install python-dotenv google-genai ollama
    pip install langchain-core langchain_ollama
